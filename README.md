
Salesforce Lead Management Automation
====================================

Description
-----------
Example Salesforce project showcasing:
- Apex trigger & handler to auto-assign leads
- Apex class for assignment rules
- Lightning Web Component (LWC) example to display lead details
- Flow description (metadata not included) for automation

This repository contains example code snippets you can paste into a Salesforce org (Developer Edition)
or include in a Salesforce DX project.

Files
-----
- apex/LeadAssignmentHandler.cls
- apex/LeadAssignmentHandler.cls-meta.xml
- apex/LeadTrigger.trigger
- lwc/leadCard/leadCard.html
- lwc/leadCard/leadCard.js
- lwc/leadCard/leadCard.js-meta.xml
- README.md

Certification
-------------
